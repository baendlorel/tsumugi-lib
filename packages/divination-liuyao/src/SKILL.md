## 装卦工具使用

**使用parser.skill.mjs解析卦象**

```bash
node parser.skill.mjs <卦象字符串> <日期>
```

- **卦象字符串格式**：可以是多种形式

  - 二进制：`000111`（0为阴爻，1为阳爻，从下到上）
  - 八卦名：`坤坤震乾坎坎`（由下卦到上卦）
  - 卦名：`天风姤`（上卦下卦）
- **日期格式**：占卜的具体日期，用于确定月建、日辰
- **输出格式**：JSON格式，包含：

  - 爻象信息（阴阳、位置）
  - 六亲配置（父母、兄弟、子孙、妻财、官鬼）
  - 六神配置（青龙、朱雀、勾陈、螣蛇、白虎、玄武）
  - 世应位置
  - 变爻信息（如有动爻）

## 解卦工作流程

1. **装卦**：使用parser.skill.mjs将卦象字符串转换为完整的卦象信息（世应、六亲、六神）
2. **定用神**：根据占卜事项确定用神（查看道理篇中的用神确定方法）
3. **分析旺衰**：结合月建、日辰分析用神旺衰
4. **查特殊格局**：旬空、月破、暗动、反伏、六合、六冲等
5. **定应期**：根据动爻、变爻生克关系推断应期

## 核心原则

- **分占之法**：一事一占，近病久病有别
- **神兆机于动**：动爻为卦中关键，重点分析
- **先理论后实例**：先读道理篇，再根据事项读对应分类文件中的理论和案例
- **六亲为用**：以六亲（父母、兄弟、子孙、妻财、官鬼）为分析基础
- **五行生克**：通过五行相生相克判断吉凶
