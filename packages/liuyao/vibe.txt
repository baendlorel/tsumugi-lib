现在需要让parser.skill.ts能够增加一个read file能力
它会把文件中的卦象字符串读取出来并输出为json数组
这是因为这个技能与obsidian-liuyao插件深度合作。
obsidian-liuyao插件里面的卦象写法语法为如下大括号中的格式
{
```liuyao
阳数字符串
```
}
{
```liuyao
日期字符串
阳数字符串
```
}
只有这两种。
因此你的做法是，增加一个与其他命令互斥的命令叫"--read-obsidian"
它会把整个文件读取为字符串str
然后str split \n 再提取出符合图中格式的字符串
分别解析它们，并返回json信息：
{
  文件路径：“”,
  卦象:[
    {
      使用toJSON的结果：{。。。},
      在文件的第几行：<行号>
    }
  ]
}
