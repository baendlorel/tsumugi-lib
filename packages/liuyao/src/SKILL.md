## 装卦工具使用

**使用parser.skill.mjs解析卦象**

```bash
node parser.skill.mjs <卦象字符串> [--date=<日期>] [--format=<格式>]
```

- **输出格式**：`--format` 可选，不写时默认 `json`
  - `json`（默认）：紧凑 JSON，`JSON.stringify(obj)`
  - `pretty-json`：缩进两格的 JSON，`JSON.stringify(obj, null, 2)`
  - `yaml`：YAML 文本
  - `md`：Markdown 排盘表格，本卦逐爻列出，变卦只标动爻装卦

- **卦象字符串格式**：由初爻到上爻，可以是多种形式
  - 六位阳数：`112233`（0 老阴、1 少阳、2 少阴、3 老阳，0 和 3 为动爻）
  - 六位单拆重交：`单单拆拆重重`（交单拆重对应阳数 0 1 2 3）
  - 卦名或全名：`天风姤`、`姤`、`天火`（名字不含动爻信息，得到的是静卦）

- **日期**：用 `--date=<日期>` 传入占卜的具体时间，交给 `new Date` 直接解析，用于确定月建、日辰，如 `--date=2026-10-31T13:00`。**请把日期和时间写全**：`new Date` 对纯日期 `2026-10-31` 按 UTC 零点解析（不是本地零点），在中国会固定成辰时，在 UTC 以西的时区会退到前一天，日辰和时辰都会错；带时间的 `2026-10-31T13:00` 才按本地时区解析
- **输出内容**：爻象信息（阴阳、位置）、六亲配置（父母、兄弟、子孙、妻财、官鬼）、六神配置（青龙、朱雀、勾陈、螣蛇、白虎、玄武）、世应位置、变爻信息（如有动爻）

### 读取笔记 / 文件里的卦

> **优先使用**：当用户给的是**文件路径或笔记**（例如 Obsidian 笔记、Markdown 文档、导出文本），或让你「看看这篇笔记里的卦」「读一下这个文件」时，**先**用 `--code-blocks` 一次读出文件里所有卦，不要自己逐行读文件、也不要把卦象字符串手动抄出来逐个调用。它比人工抄写更快、更准，且会保留每个卦在文件里的行号和日期。

```bash
node parser.skill.mjs --code-blocks=<文件路径>
```

它扫描整个文件里所有 ` ```liuyao ` 代码块，与其他参数互斥。任何工具写进 Markdown 的这类代码块都能读到，不限于 obsidian-liuyao 插件。

输出是缩进两格的 JSON。`行号` 是该代码块开头 ```liuyao 所在行（从 1 开始），有日期时按该日期排盘并附带 `时辰`和六神；没有日期时该卦不带`时辰`，解卦时需要问用户占卜时间：

```json
{
  "文件路径": "note.md",
  "卦象": [
    { "行号": 4, "卦象": { "本卦": { "...": "同上文 toJSON 的结构" } } },
    { "行号": 9, "卦象": { "...": "..." }, "时辰": { "年": "丙午", "月": "戊戌", "日": "戊寅", "时": "未" } }
  ]
}
```

文件里没有代码块时 `卦象` 是空数组。若某个块的行数、日期或卦象串不合法，脚本会报出「文件路径 第 N 行」并退出，不会静默跳过。

## 解卦工作流程

1. **装卦**：使用parser.skill.mjs将卦象字符串转换为完整的卦象信息（世应、六亲、六神）。若用户提供的是文件或笔记，先用 `--code-blocks` 读出文件里的全部卦，再逐个解
2. **定用神**：根据占卜事项确定用神（查看道理篇中的用神确定方法）
3. **分析旺衰**：结合月建、日辰分析用神旺衰
4. **查特殊格局**：旬空、月破、暗动、反伏、六合、六冲等
5. **定应期**：根据动爻、变爻生克关系推断应期

## 核心原则

- **分占之法**：一事一占，近病久病有别
- **神兆机于动**：动爻为卦中关键，重点分析
- **先理论后实例**：先读道理篇，再根据事项读对应分类文件中的理论和案例
- **六亲为用**：以六亲（父母、兄弟、子孙、妻财、官鬼）为分析基础
- **五行生克**：通过五行相生相克判断吉凶
